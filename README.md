# NC旋盤 ツールパス描画ツール

Fanuc系CNC**旋盤（ターニング）**のNCプログラムを読み込み、ツールパスを2Dで描画する**単一HTMLファイル**のツールです。外部ライブラリ非依存で、ブラウザで開くだけで動作します。

## 使い方

`index.html` をブラウザで開き、「ファイルを開く」ボタンまたはドラッグ&ドロップでNCファイルを読み込みます。

```
start index.html    # Windows
```

## 座標系・描画ルール

| 項目 | 仕様 |
|---|---|
| 横軸 | Z（軸方向、右が＋） |
| 縦軸 | X＝**直径**指令。半径＝X/2で描画 |
| 対称性 | 中心線（X=0）を軸に**上下対称**でミラー描画 |
| アスペクト比 | 等倍（歪ませない） |
| 表示対象 | ツールパスのみ（素材輪郭は描かない） |
| テーマ | ダーク/ライト両対応 |

## パーサ仕様

- **括弧内 `(...)` はコメント扱いで無視**（代替寸法値も対象外）
- モーダルG指令に対応（座標のみの行は直前のG種別を継承）
- `X`=絶対直径 / `Z`=絶対 / `U`=増分直径 / `W`=増分
- **非切削指令の除外**：`G4`（ドウェル、U/Wを移動と誤認しない）、`G28`（原点復帰）、`G50`（座標設定＝位置確定のみ）、`G96/G97/G99/G40` 等
- 工具ステーション判定：T値≥100は `floor(値/100)`（T200/T202→2、T100→1、T300→3）
- モーダル送り速度Fを保持（再生の所要時間に使用）

## 描画・色分け

| 移動種別 | 表示 |
|---|---|
| G0 早送り | 点線・淡色 |
| G1 切削 | 実線 |
| G2/G3 円弧 | 曲線（劣弧・向き自動判定） |

- 切削線は**工具ごとに色分け**（T1=青, T2=橙, T3=緑, …）
- 中心線・グリッド・目盛（Z値・⌀直径値）表示

## 機能一覧

### 基本操作
- **ズーム**（ホイール、カーソル中心）／**パン**（ドラッグ）／**ビューリセット**
- **ファイル読込**：ボタン ＋ ドラッグ&ドロップ（初期は空表示）
- **ファイル保存**：座標アシストで編集したプログラムを元のファイル名で書き出し
- **ホバー**：ツールチップ（G種別・工具・始点/終点⌀X・Z・行番号）＋ NCソース一覧と相互ハイライト

### トグル
- 早送り(G0)表示 ON/OFF
- ラベル（座標目盛）ON/OFF
- **方向**：各セグメントに進行方向の矢印
- **円弧向き反転**（前置/後置刃物台対応）
- **交点測定**
- **座標アシスト**（交点測定とは排他）

### 再生（トランスポートバー）
- ▶/⏸ 再生・一時停止、⏮ 先頭、◀/▶| ブロックステップ
- 進捗スライダー（シーク）、速度調整（0.1〜5倍）
- 先端マーカー（工具色＋進行方向矢印）がパスをなぞり順次描画
- 再生位置のNC行を自動ハイライト＆スクロール

### 工具ごとの原位置指定（凡例内）
- 各工具に ⌀X / Z を入力 → その工具の最初の移動を**原位置からのアプローチ**として描画、原位置に⊕マーカー
- 空欄なら前工具からの連続追跡（従来動作）

### G1テーパ角表示
- G1テーパ線にホバー → `水平から ∠±XX.XX°`（**半径基準**＝図面通りの片角、符号付き）
- 符号の定義は[座標アシスト](#座標アシスト拘束付き座標編集)と共通
- 純粋な外径（≈0°）・端面（≈90°）は表示しない

### G1理論交点測定
- `交点測定`ON → G1線を**2本クリック** → 2線を延長した理論交点（面取り/R前の鋭い角）に×と `⌀X Z` を固定表示、各元線から点線の延長線を描画
- 平行な2線は「交点なし」／`交点クリア`で消去
- 交点は**2線の行番号で保持**し、座標は毎回その時点のプログラムから解き直します。座標アシストで線を編集すると交点の表示も追従します
- 測った交点は[座標アシストで直接動かせます](#理論交点を動かす)

### 座標アシスト（拘束付き座標編集）
始点と角度を固定したまま終点⌀Xを変えれば終点Zが自動で決まる、といった**拘束付きの座標編集**を行い、その結果をNCプログラムに書き戻せます。

**使い方**
1. `座標アシスト`ON → 図の線をクリック、または右のNCソース行をクリック（ソース行クリックはモード不問）。G0/G1/G2/G3すべて選択可
2. 右下のパネルで `始点⌀X` / `始点Z` / `終点⌀X` / `終点Z` / `角度` の**1つを「自動」に指定**（既定は終点Z）
3. 自動でない値を入力すると自動側が即座に解け、図に**破線のゴースト線**でプレビュー表示
4. `適用` でNCプログラムの該当行を書き換え → `ファイルを保存` でダウンロード

**自動計算は「1つの点」の中で完結します。** 自動対象に座標を選ぶと、その座標が属する点が「動かす点」になり、**もう一方の点は基準（アンカー）として読み取り専用**になります。触っていない点が勝手に動くことはありません。パネルの先頭に `動かす点: 始点（終点は基準）` のように表示されます。

| 自動 | 動かす点 | 編集できる欄 | 読み取り専用 |
|---|---|---|---|
| `始点⌀X` | 始点 | 始点Z, 角度 | 終点⌀X, 終点Z（基準） |
| `始点Z` | 始点 | 始点⌀X, 角度 | 終点⌀X, 終点Z（基準） |
| `終点⌀X` | 終点 | 終点Z, 角度 | 始点⌀X, 始点Z（基準） |
| `終点Z`（既定） | 終点 | 終点⌀X, 角度 | 始点⌀X, 始点Z（基準） |
| `角度` | （なし） | 始点⌀X, 始点Z, 終点⌀X, 終点Z | — |

- 例：`自動=始点Z` にして `始点⌀X` を変えると、角度と終点はそのままで **始点Zだけ**が決まります。
- `自動=角度` は自動になる「点」が存在しないモードなので、両端とも入力できます（両端を決めて角度を読む用途）。
- 自動対象のラジオは基準側の行にも表示されるので、そこをクリックすれば動かす点を切り替えられます。

#### 理論交点を動かす

図面で押さえたい寸法は**理論交点のZ/⌀**であることが多いので、それを直接指定できます。
`交点測定` で先に交点を作ってから `座標アシスト` に切り替えてください（2つのモードは排他）。

選択した線に測定済みの交点が乗っていると、パネルに `交点①⌀X` / `交点①Z` の行が出ます。普段は読み取り専用で、始点や終点を動かすと**連動して更新**されるので、狙い値を見ながら合わせられます。その行の `自動` を選ぶと交点そのものを動かせます。

```
      線 P（相手線・固定）
            \
             × 交点   ← Z を入力 → ⌀X は線 P 上で決まる
              \
               \  線 A（選択中・作り直される）
                ● 始点   ← 線 A × 前ブロックの線
               /|
      前ブロック |         （向きはそのまま、長さだけ変わる）
      （固定）  |
                ● 終点（アンカー・不動）
```

| 手順 | 決まるもの | 根拠 |
|---|---|---|
| 1 | 交点⌀X | 交点は相手線の上にある（相手線は動かさない） |
| 2 | 角度 | 線A＝アンカーと交点を通る直線 |
| 3 | 始点⌀X・始点Z | 線A と 前ブロックの線 の交点 |

`アンカー`（動かさない端点）は 始点／終点 から選べます。終点アンカーなら始点が前ブロックの線上を、始点アンカーなら終点が次ブロックの線上を動きます。書き換わるのは前者が前ブロックの行、後者が選択ブロックの行だけです。

交点が複数乗っている場合はすべて並び、**自動にできるのは1つ**。選ばなかった交点も連動して更新されるので、線を動かした影響がその場で見えます。

次の場合は交点を動かせず、理由を表示します。

| 条件 | 理由 |
|---|---|
| 選択行が⌀XまたはZを省略/増分指定 | 角度を変えるには両軸の明示指定が必要。`固定` ボタンで解除できます |
| 動く端点側の隣ブロックが無い／円弧／新しい線と平行 | 端点を拘束できません |
| 隣ブロックが相手線と同一 | 端点が交点に退化します |
| アンカー=終点で始点が編集不可 | 下の「始点の編集」の条件と同じ |
| 相手線が入力軸方向に退化 | 例：相手線が端面（Z一定）なら交点Zは動かせないので、`自動=交点Z` にして⌀Xで入力します |

**角度の定義（半径基準・符号付き -90〜90°）**

```
角度 = atan( ((終点X - 始点X)/2) / (終点Z - 始点Z) )
```

| 値 | 意味 |
|---|---|
| `0°` | 外径（Z軸平行） |
| `±90°` | 端面（X軸平行） |
| `+` | Z+方向へ半径が拡大 |
| `-` | Z+方向へ半径が縮小 |

線の傾きそのものなので、進行方向（Z+へ切るかZ-へ切るか）には依存しません。

**始点の編集＝共有頂点を動かす**

始点は「前ブロックの終点」と同じ点なので、始点を変えると**前ブロックの行が書き換わります**（パネルにその旨と行番号を表示）。前ブロックの角度を保ったまま頂点をスライドさせたいときは、**前ブロックを選んで角度を固定し、その終点を変える**のが同じ操作になります。

始点を編集できるのは、直前のブロックの終点とこのブロックの始点が一致する（＝共有頂点の）ときだけです。次の場合は始点欄が読み取り専用になり、理由を表示します。

| 始点の出どころ | 対応 |
|---|---|
| プログラム先頭／`G28`後の位置決め／`G50`（座標系設定） | 編集不可。`G50` の書き換えは座標系を変えてしまうため対象外 |
| 工具原位置（凡例で指定したもの） | 凡例の ⌀X / Z 入力欄で変更 |

**継承軸の「追従」**

現ブロックの行が片方の軸を省略している（例：`Z2.7` は X省略）／増分 `U`・`W` で指定している場合、その軸の終点は**始点から決まります**。この状態で始点を動かすと、パネルは終点も同じだけ動かして表示し（`追従` タグ）、**その行は書き換えません**。⌀一定の外径線なら⌀一定のまま平行移動する、という自然な結果になり、省略していた語が増えることもありません。

終点をその軸で独立に決めたいときは、終点欄の隣の **`固定`** を押します。追従が解除され、欄が編集可能になり、自動対象にも選べるようになります（適用時にその軸の語を新設）。

追従する軸は、たとえ終点が基準側であってもプログラムの構造上どうしても動きます。そのためその行には `基準` ではなく `追従` タグを表示します。

**書き換えの仕様**

- 数値は**必ず小数点付き**で出力（`X40.`）。Fanucでは `X40` は 0.040mm と解釈されるため
- **括弧内 `(...)` は書き換えません**。代替寸法が入っている行（前ブロック側も含む）にはパネルに注意書きを表示
- 元の行が `U`/`W`（増分）ならその形式を保ったまま、**新しい始点を基準に**増分値を計算して書き込む
- 該当する座標語が無い行には**新設**し、ワード順の慣例（`N`/`O` → `G` → `X`/`U` → `Z`/`W` → `R` → `T` → `F` → `S` → `M`）を保つ位置に挿入
- 座標は小数点以下3桁に丸めるため、短いセグメントでは指定角度から 0.05°程度ずれることがあります。適用後のパネルは**実際にプログラムに書かれた値から再計算した角度**を表示します
- G2/G3（円弧）は角度拘束の対象外。`始点⌀X` / `始点Z` / `終点⌀X` / `終点Z` / `R` の直接編集のみ
- 終点を変えると次ブロックの始点も変わります。次ブロックが軸を省略／増分指定している場合は後続にも波及する旨をパネルに表示

**元に戻す・保存**

- `戻す` ボタンまたは `Ctrl+Z` で1段ずつ取り消し
- Escape は**まず編集の選択を解除**し、解除するものが無ければ交点をクリア（測った交点を編集の足場に使うため）。`交点クリア` ボタンは一度で全消し
- 未保存の編集があるとファイル名に `*` が付き、ページを離れる際に警告
- `ファイルを保存` は元のファイル名・改行コードを保ったまま書き出し

## 対応環境

モダンブラウザ（Chrome / Edge / Firefox 等）。インストール不要。
