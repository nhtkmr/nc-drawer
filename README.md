# NC旋盤 ツールパス描画ツール

Fanuc系CNC**旋盤（ターニング）**のNCプログラムを読み込み、ツールパスを2Dで描画する**単一HTMLファイル**のツールです。外部ライブラリ非依存で、ブラウザで開くだけで動作します。

## 使い方

`index.html` をブラウザで開き、「ファイルを開く」ボタンまたはドラッグ&ドロップでNCファイルを読み込みます。

```
start index.html    # Windows
```

## 座標系・描画ルール

| 項目 | 仕様 |
|---|---|
| 横軸 | Z（軸方向、右が＋） |
| 縦軸 | X＝**直径**指令。半径＝X/2で描画 |
| 対称性 | 中心線（X=0）を軸に**上下対称**でミラー描画 |
| アスペクト比 | 等倍（歪ませない） |
| 表示対象 | ツールパスのみ（素材輪郭は描かない） |
| テーマ | ダーク/ライト両対応 |

## パーサ仕様

- **括弧内 `(...)` はコメント扱いで無視**（代替寸法値も対象外）
- モーダルG指令に対応（座標のみの行は直前のG種別を継承）
- `X`=絶対直径 / `Z`=絶対 / `U`=増分直径 / `W`=増分
- **非切削指令の除外**：`G4`（ドウェル、U/Wを移動と誤認しない）、`G28`（原点復帰）、`G50`（座標設定＝位置確定のみ）、`G96/G97/G99/G40` 等
- 工具ステーション判定：T値≥100は `floor(値/100)`（T200/T202→2、T100→1、T300→3）
- モーダル送り速度Fを保持（再生の所要時間に使用）

## 描画・色分け

| 移動種別 | 表示 |
|---|---|
| G0 早送り | 点線・淡色 |
| G1 切削 | 実線 |
| G2/G3 円弧 | 曲線（劣弧・向き自動判定） |

- 切削線は**工具ごとに色分け**（T1=青, T2=橙, T3=緑, …）
- 中心線・グリッド・目盛（Z値・⌀直径値）表示

## 機能一覧

### 基本操作
- **ズーム**（ホイール、カーソル中心）／**パン**（ドラッグ）／**ビューリセット**
- **ファイル読込**：ボタン ＋ ドラッグ&ドロップ（初期は空表示）
- **ホバー**：ツールチップ（G種別・工具・始点/終点⌀X・Z・行番号）＋ NCソース一覧と相互ハイライト

### トグル
- 早送り(G0)表示 ON/OFF
- ラベル（座標目盛）ON/OFF
- **方向**：各セグメントに進行方向の矢印
- **円弧向き反転**（前置/後置刃物台対応）
- **交点測定**

### 再生（トランスポートバー）
- ▶/⏸ 再生・一時停止、⏮ 先頭、◀/▶| ブロックステップ
- 進捗スライダー（シーク）、速度調整（0.1〜5倍）
- 先端マーカー（工具色＋進行方向矢印）がパスをなぞり順次描画
- 再生位置のNC行を自動ハイライト＆スクロール

### 工具ごとの原位置指定（凡例内）
- 各工具に ⌀X / Z を入力 → その工具の最初の移動を**原位置からのアプローチ**として描画、原位置に⊕マーカー
- 空欄なら前工具からの連続追跡（従来動作）

### G1テーパ角表示
- G1テーパ線にホバー → `水平から ∠XX.XX°`（**半径基準**＝図面通りの片角）
- 純粋な端面（≈0°）・外径（≈90°）は表示しない

### G1理論交点測定
- `交点測定`ON → G1線を**2本クリック** → 2線を延長した理論交点（面取り/R前の鋭い角）に×と `⌀X Z` を固定表示、各元線から点線の延長線を描画
- 平行な2線は「交点なし」／`交点クリア`・Escapeで消去

## 対応環境

モダンブラウザ（Chrome / Edge / Firefox 等）。インストール不要。
